# Xiangqi Movement Spec (Change 002)

Reference living spec at `openspec/specs/xiangqi/movement/spec.md`.

- General: 1 step orthogonal, inside Palace.
- Advisor: 1 step diagonal, inside Palace.
- Elephant: 2 steps diagonal, own side of river only, blocked if elephant eye occupied.
- Horse: L movement, blocked if horse leg occupied.
- Chariot: Orthogonal rays, cannot jump.
- Cannon: Orthogonal rays without jump for quiet moves; requires exactly 1 screen to capture.
- Soldier: Forward 1 step before river; forward/left/right 1 step after river; never backward.
